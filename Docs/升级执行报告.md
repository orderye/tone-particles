## 3. 文件级改动

共 56 个文件、+5401 / -337 行。核心改动：

### 阶段一（`52446e3`）

- **`scripts/_core.py`**：新增 `atomic_write_text`（唯一临时文件 + fsync + 原子替换 + 失败清理）、`config_lock`（POSIX `flock` / Windows `msvcrt`，超时与异常释放）、`validate_config`（错误 / 告警分流）、`update_config_file`（加锁的读—改—写，配置更新的唯一入口）；`save_config` 改为写前归一化校验 + 写后重新读取校验；`normalize_config` / `migrate_config` / `apply_config_patch` 改为不改动调用方对象；未知字段默认保留并告警，越界数值夹取并留痕。
  *接口影响*：`save_config(path, cfg)` 签名兼容，新增参数都是 keyword-only 且有默认值。
- **`integrations/host_adapter.py`**：`next_turn` 的状态提交时机改为「提示词拼装成功之后」；新增 `user_dir` 与 `TONE_PARTICLES_USER_DIR` 隔离多用户配置与历史；`update_config` 改走 `update_config_file`。
- **`mcp/server.py`**：schema 驱动的参数校验（类型 / 枚举 / 长度 / 范围 → `-32602`；未知参数 → 工具级错误，不再静默丢弃）；单条消息出错不再终止服务；`params` / `arguments` 类型校验。
- **`mcp/schemas.py`**：新增 `validate_arguments`；`get_style_prompt` 增加可选 `context`（阶段三）。
- **`mcp/tools.py`**：`set_user_style` 改走加锁的读—改—写，写成功之后才返回。
- **`tools/version.py`**（新）：版本号同步，减少重复硬编码。

### 阶段二（`8073d33`）

- **`eval/judge/common.py`**：指标容器引入 `status`（`passed` / `failed` / `not_evaluated` / `blocked`），保留旧的 `passed` / `skipped` 字段；新增 `blocked_metric` 与 `call_judge`（区分「评审没结论」与「评审通道出错」）。
- **`eval/judge/anchors.py`**（新）：确定性的语义锚点保真（数字按「独立数字」匹配，`120` 不会被 `1200` 误判为命中）。
- **`eval/judge/blind.py` / `fidelity.py` / `fusion.py`**：通道出错记「被阻塞」，评审没作答记「未评测」；融合指标在无后端时不再把确定性参考值渲染成达标；保真指标写明运行时边界；盲测新增泄漏检查（回复里出现目标风格名即判失败）。
- **`eval/run.py`**：新增 `--strict` / `--strict-all`（退出码 2）、`--seed`、`--skip-validate`；报告元信息补上仓库版本、Git commit、Python 版本、平台、评测数据哈希、后端元信息、分母定义。
- **`eval/report.py`**：渲染四种状态、三类明细（未通过 / 未计入 / 被阻塞）、发布阻断项，带 `报告 schema 版本`。

| 压力测试的样本量有限 | 并发测试用 6 个子进程、3000 轮抽样，跑在一台机器上 | `tests/test_config.py`、`tests/test_core.py` | 否 | 不能据此宣称「在所有文件系统 / 操作系统上没有并发风险」；换文件系统（NFS、APFS 以外）需重跑 |
